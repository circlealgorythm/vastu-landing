# Project Guide: Лендинг «Васту-геометрия»

> **Экосистема:** Школа AisuKam (`vastu.aisukam.ru`)  
> **Стек:** Vite, React 19, TypeScript, Three.js / React Three Fiber, Custom CSS  
> **Сквозные стандарты школы:** Перед реализацией общих UI/UX (модалки, скроллбары) или аналитики сверяться с [.harness/lessons.md](file:///./.harness/lessons.md).  
> **Локальный журнал прогресса:** [progress.md](file:///./projects/landing-vastu/progress.md)

---

## 1. Структура проекта
- `src/App.tsx`: Основной интерфейс лендинга и форма заявки.
- `src/index.css`: Кастомные стили и анимации лендинга.
- `public/`: Статические ассеты (секвенции кадров, иконки).
- `temple.glb`: 3D-модель храма (~84 МБ).

---

## 2. Критические архитектурные инварианты

1. **Оптимизация 3D-модели (TD-001):**
   - Модель `temple.glb` весит ~84 МБ. Это блокирует быструю загрузку лендинга.
   - Запрещено деплоить модель в продакшн без сжатия (Draco / Meshopt). Целевой размер — менее 3–5 МБ.
   - Компонент 3D должен загружаться отложено (`React.lazy` / `Suspense`) только при приближении к первому экрану.

2. **Интеграция лид-формы (TD-002):**
   - Текущая форма заявки вызывает заглушку `setSubmitted(true)`.
   - При доработке подключить отправку вебхука в GetCourse / Google Sheets CRM с сохранением UTM-меток аналогично сайту свечей.

---

## 3. Верификация
После внесения изменений обязательно выполнить:
```bash
npm run build
```
Команда выполняет проверку типов TypeScript (`tsc -b`) и сборку Vite. Сборка должна проходить с 0 ошибок.
